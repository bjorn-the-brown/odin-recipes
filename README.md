# TOP Project: Odin Recipes

This is a practice project where I will create a basic recipe website.
The purpose of this project is to practice my foundational HTML knowledge.

By the end of this project, I should have demonstrated my understanding of working wtih basic HTML including:
- Creating appropriate files and directories for a basic HTML web project
- Creating HTML documents with HTML boilerplate
- Understanding the basics of HTML elements and attributes
- Working with text (formatting and structure, appropriate use of headings, paragraphs, etc.)
- Working with lists
- Working with links and images

Addtionally, this project will serve as an opportunity to practice working with a CLI, Linux, VSCode, Git and Github.
