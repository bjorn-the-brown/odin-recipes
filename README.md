# TOP Project: Odin Recipes

## HTML Foundations

This is a practice project where I will create a basic recipe website.
The purpose of this project is to practice my foundational HTML knowledge.

By the end of this project, I should have demonstrated my understanding of working wtih basic HTML including:
- Creating appropriate files and directories for a basic HTML web project
- Creating HTML documents with HTML boilerplate
- Understanding the basics of HTML syntax
- Working with text (formatting and structure, appropriate use of headings, paragraphs, etc.)
- Working with lists
- Working with links and images

Addtionally, this project will serve as an opportunity to practice working with a CLI, Linux, VSCodium, Git and Github.

## Update: CSS Foundations

Returning to this project after working through the CSS Foundations part of The Odin Project, I will add basic CSS styling to the website.
This will serve as an opportunity to practice the following:
- Using the external CSS method
- CSS syntax
- Basic CSS (layout, colors, typography properties, etc.)
- Understanding the Box Model, HTML display types (block, inline, inline-block), and Normal Flow.
- Understanding the CSS Cascade
- Inpecting HTML and CSS using Chrome Dev Tools
